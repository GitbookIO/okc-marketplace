# Index

Every folder in this repo, with what it holds. There are no indexes inside folders: list a folder to see its pages.

## Concepts

- [API reference](docs/reference/): one page per API operation, kept in step with the spec in `api/openapi.yaml`.
- [Guides](docs/guides/): task guides that walk through the API, kept in step with the reference.
- [Changelog](docs/changelog/): one entry per API change, named by date, so the folder reads in order.
- [Docs gaps](gaps/): one page per question customers ask that the docs don't answer yet, with the threads that asked it and a count.
- [Digests](digests/): one summary per week.

## Records

- [Support threads](support/): one file per closed support conversation.
- [Pull requests](prs/): one file per pull request that changed how the API behaves.

## Everything else

- [API spec](api/): the OpenAPI spec. People edit it, and workflows read it but never write it.
- [Inbox](inbox/): drop pasted text or files here for Ingest inbox to sort.
- [Archive](archive/): inbox items that have been processed.
- [Types](types/): one definition per type, with the fields it uses.
- [Workflows](workflows/): the workflows that keep this repo current.
