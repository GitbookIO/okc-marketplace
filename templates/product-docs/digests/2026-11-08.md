## API changes

- 3 November 2026, 1.14.0: [Ask for a signature on delivery](../docs/changelog/2026-11-03-signature-required.md). Create a shipment takes signature_required, and every shipment returns it.
- 6 November 2026, 1.15.0: [Choose the label format](../docs/changelog/2026-11-06-label-format.md). Buy a label takes label_format: pdf_4x6, pdf_a4 or zpl.
