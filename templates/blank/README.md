# Blank

A blank OKC repo: Markdown pages with frontmatter, kept current by the workflows you add, with every change reviewed on a branch. Start here when no template fits.

## Folders

- `inbox/`: drop pasted text or files here. Add an Ingest inbox workflow to sort them into records.
- `archive/`: inbox items that have been processed.
- `types/`: one definition per type, with the fields it uses.
- `workflows/`: the workflows that keep this repo current. Its README explains how they work.
- `index.md`: a map of every folder.
- `log.md`: one line per workflow run, newest first.
