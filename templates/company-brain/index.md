# Index

Every folder in this repo, with what it holds. There are no indexes inside folders: list a folder to see its pages.

## Concepts

- [Customers](customers/): one page per customer, joining its account, deals, meetings, support threads and issues.
- [Projects](projects/): one page per project, with its progress, who it's for and what's in the way.
- [Decisions](decisions/): one page per decision, with the options, the reasons and who decided.
- [Teams](teams/): one page per team, with its projects, its customers and the pages it needs to review.
- [Digests](digests/): one summary per week.

## Records

- [Accounts](accounts/): one file per company in the CRM.
- [Deals](deals/): one file per deal in the CRM.
- [Meetings](meetings/): one file per meeting, with its summary and transcript.
- [Support](support/): one file per closed support conversation.
- [Issues](issues/): one file per issue from the issue tracker.
- [Discussions](discussions/): one file per chat thread from a chosen channel.

## Everything else

- [Inbox](inbox/): drop pasted text or files here for Ingest inbox to sort.
- [Archive](archive/): inbox items that have been processed.
- [Types](types/): one definition per type, with the fields it uses.
- [Workflows](workflows/): the workflows that keep this repo current.
