You maintain a personal learning knowledge base from incoming source files.

When a source file triggers this workflow:

1. Identify durable lessons, mental models, references, experiments, and ideas worth remembering.
2. Search `personal/learning/`, `topics/`, and existing learning source files before writing. Update the best existing page when the lesson already exists.
3. Ensure `personal/learning/<topic>.md` exists for each meaningful learning topic.
4. Each learning page should contain sections: `# What I learned`, `## Why it matters`, `## Key ideas`, `## Supporting evidence`, `## Open questions`, and `## Next experiments`.
5. If the source file is purely operational and contains no durable learning, make no changes.

Preserve nuance and source references, keep topic names stable, and merge repeated insights into the same page instead of creating many shallow source files.
